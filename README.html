Capabilities

A practical first-pass review.

SHIPSHAPE surfaces potential problems; it does not replace code review, testing, or dedicated security tools.

⌕

Relative imports

Checks whether relative import paths appear to resolve to existing files.

⚑

TODO / FIXME

Finds TODO and FIXME markers that may deserve attention before release.

◇

Possible secrets

Flags patterns that may indicate hardcoded secrets. Review each finding manually.

{ }

Package configuration

Checks package.json validity and selected common configuration issues.

▶

Optional tests

With --run-tests, runs the target project's configured npm test script and records the result.

▤

Reports and exit codes

Creates JSON and HTML reports and supports CI-friendly failure exit codes.

Installation

Get it running locally.

Requires Node.js 18 or later. npm is needed for installation and for running project tests.

Install the local package

Run this from the directory containing the package file, or use its full path.

npm install -g ./shipshape-1.0.0.tgz

Confirm installation

On Windows PowerShell, use the .cmd shim if execution policy blocks the .ps1 shim.

shipshape --help

# PowerShell alternative
shipshape.cmd --help
Quick start

Scan, inspect, improve.

Replace ./my-project with the path to the project you want to scan.

Run a scan

shipshape ./my-project

Fail on warnings or errors

shipshape ./my-project --fail-on-warning

Run configured tests

shipshape ./my-project --run-tests

CLI options

OptionBehavior
--help, -hDisplay help.
--fail-on-errorExit with code 1 if errors are found.
--fail-on-warningExit with code 1 if errors or warnings are found.
--run-testsExplicitly run the project's npm test script.

Where reports are saved

SHIPSHAPE writes shipshape-report.json and shipshape-report.html to the current working directory—the directory from which you run the command, not necessarily the project being scanned.

Know the limits

Useful signals, not a guarantee.

Early-stage software.

SHIPSHAPE uses heuristic checks. Findings may be false positives, and a clean scan does not guarantee that a project is secure, bug-free, or ready for release.

Review findings and run appropriate tests independently. Only use --run-tests when you intend to execute the target project's configured test command; project scripts can execute arbitrary code.

Independent testing and feedback are needed before relying on SHIPSHAPE in production.
